vir tutor
=========

Generate a workspace for the Virdant guide.

Usage
-----
.. code-block:: console

  $ vir tutor

``vir tutor`` sets up a workspace with all the starter files the
:doc:`/guide/index` needs,
so you can follow along without copying examples by hand.

It creates the workspace in your current directory,
initializing a Git repository for it (unless one is already there,
or you pass ``--no-git``).

Options
-------
``--no-git``
    Do not initialize a Git repository for the guide workspace.
