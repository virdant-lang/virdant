# Instructions
Always follow the Garden Guidelines when reviewing staged changes to Virdant:
These are found in `GARDEN_GUIDELINES.md` in the root directory.

When reviewing DO NOT RUN ANY tests or `cargo` or `vir` at all for any reason.

If I say "fix" immediately after creating the `CORRECTION_PROMPT.md` file,
read it and fix everything in it.

When you are done fixing everything, delete `CORRECTION_PROMPT.md`.
