# syntax

Parser- and lexer-level errors:

- `parser_errors.vir` — assorted syntax errors (was `errors/syntax.vir`).
- `tabs.vir` — tab characters are not allowed in indentation
  (was `errors/tab.vir`).
- `indentation.vir` — lines must be indented by multiples of 4 spaces.
- `docstring_no_space.vir` — docstring markers require a following space.
